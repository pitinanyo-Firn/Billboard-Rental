  4. Commit message: "Version 62: AI insight + API Key + attachments" → กด Commit changes
  5. รอ 1–2 นาที แล้วเปิด https://vercel.com/firn1/billboard-rental-5igo → Deployment ล่าสุดต้องเป็น Ready
