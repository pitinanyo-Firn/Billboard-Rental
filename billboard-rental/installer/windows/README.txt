Billboard Rental Hub — ตัวติดตั้ง Windows
Plan B Media · https://billboard-rental.vercel.app/

ติดตั้ง
  1. ดับเบิลคลิก Install.cmd
     (ถ้า Windows ขึ้น "Windows protected your PC" ให้กด More info → Run anyway — เป็นสคริปต์ของระบบเอง)
  2. รอข้อความ "ติดตั้งเรียบร้อย" → กด Yes เพื่อเปิดโปรแกรม
  3. ครั้งต่อไปเปิดจากไอคอน "Billboard Rental Hub" บน Desktop หรือ Start Menu

ไม่ต้องใช้สิทธิ์ admin · ติดตั้งเฉพาะผู้ใช้ที่ล็อกอิน Windows อยู่
โปรแกรมเปิดระบบในหน้าต่างแยกของ Microsoft Edge (หรือ Google Chrome ถ้าไม่มี Edge)
อัปเดตเป็นเวอร์ชันล่าสุดเองทุกครั้งที่เปิด — ไม่ต้องติดตั้งใหม่
ข้อมูลทั้งหมดอยู่ใน Google Sheet เหมือนเดิม (ไม่มีข้อมูลเก็บในเครื่อง)

ถอนการติดตั้ง
  Settings → Apps → Billboard Rental Hub → Uninstall
  หรือดับเบิลคลิก Uninstall.cmd

ตัวเลือก (สำหรับผู้ดูแลระบบ)
  Install.cmd -Quiet            ติดตั้งแบบไม่มีหน้าต่างถาม
  Install.cmd -Browser chrome   บังคับใช้ Google Chrome
