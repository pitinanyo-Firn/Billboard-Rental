## 1. ภาพรวมระบบ

ระบบมี 3 ส่วนที่ทำงานร่วมกัน

| ส่วน | หน้าที่ |
|---|---|
| **หน้าเว็บ** (Vercel) | หน้าจอที่ทุกคนใช้งาน — ดู ค้นหา บันทึก แก้ไข Export |
| **Apps Script** (Web App API) | ตรวจสิทธิ์ผู้ใช้ อ่าน/เขียน Google Sheet ส่งอีเมลแจ้งเตือน |
| **Google Sheet** | ฐานข้อมูลจริงทั้งหมด |

**ข้อมูลซิงค์สองทาง** — บันทึกบนเว็บแล้วเขียนลงชีตทันที และถ้ามีคนแก้ในชีตโดยตรง หน้าเว็บจะอัปเดตเองภายในประมาณ 30–60 วินาที

|---|---|

## 4. ทะเบียนค่าเช่า

รายการค่าเช่าทั้งหมดจาก `Contract_Master`

### 4.1 ค้นหาและกรอง

- **ช่องค้นหา** — เลขที่สัญญา, ผู้รับเงิน, Media Site, PR, PO, Epicore Code
- **ตัวกรอง** — บริษัท · ประเภทสื่อ · รูปแบบการจ่าย · Status Payment · External / Inter-Co · ระดับการจ่าย
- **ล้างตัวกรอง** — กลับไปแสดงทั้งหมด
- มุมขวาแสดง "แสดง X จาก Y รายการ"

### 4.2 สีระดับการจ่าย

| สี | ระดับ | ความหมาย |
|---|---|---|
| 🟥 แดงเข้ม | เลยกำหนดจ่าย | เลยวันชำระแล้ว ยังรอเบิก |
| 🔴 แดง | ภายใน 3 วัน | ใกล้ถึงวันชำระมาก |
| 🟠 ส้ม | ใกล้ครบกำหนด | ภายใน 30 วัน |
| 🟢 เขียว | ยังไม่ถึงกำหนด / เบิกแล้ว / จ่ายแล้ว | ปกติ |
| ⚪ เทาอ่อน | งวดของปีก่อน | งวดเก่าที่ยังไม่ปิด — ควรตรวจสถานะ |
| ⚪ เทา | ไม่ระบุวันที่ | ไม่มีวันชำระในชีต |

**วันที่ต้องจ่าย** = วันชำระตามสัญญา (ถ้ายังรอเบิก) หรือ เช็คลงวันที่ (ถ้าเบิกแล้วแต่เช็คยังไม่ถึงวัน)
แถวที่มีเครื่องหมาย **!** มีปัญหาข้อมูล ดูรายละเอียดได้ในแท็บ *ตรวจสอบข้อมูล*

### 4.3 หน้ารายละเอียด

คลิกแถวใดก็ได้เพื่อเปิดรายละเอียดด้านขวา — ข้อมูลสัญญา, การจ่าย, เอกสาร, รายการรายเดือนของสัญญา, ประวัติการจ่ายและใบเสร็จ

| ปุ่ม | ใช้ทำอะไร |
|---|---|
| **💸 บันทึกจ่าย** (admin) | ไปฟอร์มบันทึกการเบิกจ่ายพร้อมเลือกรายการนี้ให้ |
| **✎ แก้ไข** (admin) | แก้ไขข้อมูลแถวนี้ |
| **⎙** | พิมพ์รายละเอียด |
| **✕** | ปิด |

### 4.4 แก้ไขข้อมูล (admin)

1. คลิกแถว → **✎ แก้ไข**
2. แก้ช่องที่ต้องการ — แบ่งเป็น 3 กลุ่ม
   - **สัญญา**: Contract No., Company, Rent, Vendor No., Vendor name, Media Type, Media Site, Epicore Code, Part Code, Part Description, Start/End Contract, Period, Status Contract
   - **การจ่าย**: Payment, Payment term, Amount/Month, Amount/Year, Up or CN, Month, ว/ด/ป ชำระตามสัญญา, รอบการจ่าย (เริ่มต้น/สิ้นสุด), Status Payment
   - **เอกสาร**: รูปแบบ (Memo/Invoice), วันที่ส่งจัดซื้อ, PR, PO, MEMO/INV No., รอบจ่ายตามเอกสาร, เช็คลงวันที่, Send ECM, ECM No., Remark
3. ด้านล่างแสดงจำนวนช่องที่แก้ → กด **บันทึกลง Google Sheet**

- ระบบตรวจรูปแบบข้อมูลก่อนบันทึก ถ้าผิดจะแสดงข้อความใต้ช่องนั้น
- ทุกการแก้ไขบันทึกใน `Log` (ค่าเดิม → ค่าใหม่)
- ถ้ามีคนแก้แถวเดียวกันในชีตไปก่อน ระบบจะไม่บันทึกทับ และให้รีเฟรชก่อน

## 5. New Contract (admin)

เพิ่มสัญญาใหม่ลงใน `Contract_Master`

1. **ส่วนที่ 1: ข้อมูลบริษัทและเอกสาร**
   - บริษัท *, ผู้ขาย (Vendor Name) *, Vendor No., Contract No. *
   - PR Number, PO Number, Start Contract *, End Contract *
   - Payment * — รายเดือน / รายปี / ราย 3 เดือน
   - ระบบคำนวณ "ระยะสัญญา X ปี Y เดือน" ให้
2. **ส่วนที่ 2: Location / Expense Period**
   - กรอก Media Type, Media Site, Epicore Code, Part Code, Part Description, ค่าเช่าตามสัญญา
   - กด **+ เพิ่ม Location** ถ้าสัญญามีหลายจุด (1 Location = 1 แถวในชีต)
3. เลือก **บันทึกลงเดือน (Month)** → กด **💾 บันทึกเข้าระบบ**

- ระบบแทรกแถวต่อท้ายกลุ่มเดือนที่เลือก และใส่ลำดับถัดไปให้เอง
- ถ้า Contract No. + ผู้ขาย ซ้ำกับที่มีอยู่ในชีต ระบบจะถามยืนยันก่อน
- ตาราง **สัญญาใหม่ที่บันทึกแล้ว** แสดงทุกสัญญาที่เพิ่มจากหน้าเว็บ กด 🗑 เพื่อลบแถวของสัญญานั้นออกจาก Contract_Master
- **ล้างฟอร์ม** — เคลียร์ทุกช่องเพื่อเริ่มใหม่

## 6. ครบกำหนดจ่าย

### 6.1 แจ้งเตือนทางอีเมล

แสดงสถานะการแจ้งเตือนอัตโนมัติและรายชื่อผู้รับ สำหรับ admin มีเครื่องมือเพิ่ม

| เครื่องมือ | ใช้ทำอะไร |
|---|---|
| **เปิดการแจ้งเตือนอัตโนมัติ** | เปิด/ติดตั้งการตรวจทุกวัน 08:00 น. (แสดงเมื่อยังไม่ได้เปิด) |
| **① แจ้งเตือนล่วงหน้า** — ดูตัวอย่างของวันนี้ / ส่งให้ฉัน | ดูหรือทดสอบอีเมลเตือนก่อนถึงกำหนด 7 วันและ 3 วัน |
| **② สรุปงานประจำเดือน** — เลือกเดือน → ดูตัวอย่าง / ส่งให้ฉัน / ส่งให้ผู้รับทั้งหมด | อีเมลสรุปรายการทั้งเดือน |

### 6.2 ตารางครบกำหนดจ่าย

งวดที่ **เลยกำหนด** และงวดที่ **ครบกำหนดภายใน 30 วัน** เรียงตามวันที่ต้องจ่าย
แสดงระดับ, วันที่ต้องจ่าย, จำนวนวันที่เหลือ, ผู้รับเงิน, Media Site, เลขที่สัญญา, การจ่าย, ยอดที่ต้องจ่าย และ Status Payment พร้อมยอดรวมด้านบน
(งวดของปีก่อนไม่นับรวม — ตรวจได้ในแท็บตรวจสอบข้อมูล)

### 6.3 หน้าต่างการเบิก — ขั้นตอนสถานะการจ่าย

ทุกงวดเดินตามขั้นตอนนี้

```
รอเบิก  ──✓ ทำเครื่องหมายเบิกแล้ว──►  เบิกแล้ว  ──💰 จ่ายแล้ว──►  จ่ายแล้ว
        ◄──────↺ กลับเป็นรอเบิก─────          ◄──↺ กลับเป็นเบิกแล้ว──
```

1. เลือกมุมมอง **รอเบิก / เบิกแล้ว / จ่ายแล้ว** (ตัวเลขคือจำนวนงวด)
2. เลือก **เดือนที่ต้องจ่าย** (หรือทุกเดือน)
3. คลิกการ์ดประเภท **ทั้งหมด / รายเดือน / ราย 3 เดือน / รายปี** — แต่ละการ์ดแสดงยอดรวมและจำนวนงวด
4. (admin) ติ๊กเลือกงวด หรือติ๊กหัวตารางเพื่อเลือกทั้งหมด → แถบสีส้มแสดงจำนวนงวดและยอดรวมที่เลือก
5. ใส่ **MEMO/INV No.** ได้ (ไม่บังคับ) → กดปุ่มเปลี่ยนสถานะ → ยืนยัน

- 1 งวดอาจมีหลายแถวในชีต (เช่น ราย 3 เดือน = 3 แถว) ระบบเปลี่ยนสถานะให้ครบทุกแถวของงวดนั้น
- มุมมอง เบิกแล้ว / จ่ายแล้ว แสดงคอลัมน์ MEMO/INV · PO แทนจำนวนวันที่เหลือ

## 7. บันทึกจ่าย / ใบเสร็จ

### 7.1 บันทึกการเบิกจ่าย (admin)

1. **เลือกรายการค่าเช่า** — กรองทีละขั้น
